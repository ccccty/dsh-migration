# 04 · 编译排错手册（报错 → 根因 → 修法）

## Tectonic 报错

| 报错 | 根因 | 修法 |
|---|---|---|
| `Package fontspec Error: The font "Noto Serif CJK SC" cannot be found` | 字体只在 D 盘主档，系统不认识 | 当前用户级安装：复制 OTF 到 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` + HKCU 注册表登记。**HKCU 注册表指向 D 盘路径的做法对 Tectonic 无效，必须真复制** |
| `failed to open input file "main"` | 传了无扩展名文件名；Tectonic 不自动补 .tex | 命令行给 `main.tex`；LaTeX Workshop recipe 里用 `%DOC_EXT%` 不用 `%DOC%` |
| `primary input not available (?!)` 三连 | 同上，输入文件打不开 | 同上 |
| 中文全部缺字（Missing character） | CJK 字体没配上或字体名写错 | 确认 `\setCJKmainfont{Noto Serif CJK SC}` 且字体已用户级安装 |
| 参考文献全 `[?]` | 用了 biblatex/biber（Tectonic 不支持） | 改 `thebibliography` 内联；或换 MiKTeX |

## LaTeX Workshop / VS Code 侧

| 现象 | 根因 | 修法 |
|---|---|---|
| `Recipe terminated with fatal error: spawn xelatex ENOENT` | main.tex 首行魔术注释 `% !TeX program = xelatex` 触发魔法注释构建路径，去 spawn 不存在的 xelatex | 三管齐下：①settings 设 `enableMagicComments:false`；②recipe.default 按名锁 `"Tectonic"`；③`D:\devtools\texbin` shim 兜底（xelatex.cmd 转发 Tectonic） |
| 改了配置不生效 | 运行中的窗口用旧配置 | Ctrl+Shift+P → 重新加载窗口；不行就完全退出重开 |
| 快捷键 Ctrl+Alt+B/V 无反应 | 光标不在 LaTeX 编辑器里（快捷键有 editorLangId 门控） | 先点进 .tex 代码区 |
| 双击启动器窗口打不开 | 见下方 Electron 坑 | 用 `D:\devtools\paper-editor.cmd` 启动（已处理） |

## DSH 环境坑（详见 references/01）

| 现象 | 根因 |
|---|---|
| VS Code 启动报 `Cannot find module <乱码路径>` | ELECTRON_RUN_AS_NODE 泄漏 + PS5.1 中文参数重编码，双重叠加 |
| `Invalid file descriptor to ICU data received` | VS Code 版本化布局被拍平（负载必须留在 `<commit>\` 子目录） |
| Get-Content 读配置报"JSON 损坏" | PS 5.1 GBK 误解码 UTF-8 无 BOM 文件，假象；用 read 工具复核 |

## 验收标准（编译后逐项）

```
exit code = 0
main.log 中 Missing character = 0
LaTeX Warning = 0（允许 cite 类提示在首遍出现，最终必须为 0）
multiply defined = 0
PDF 页数符合预期；抽取文本无 \ufffd
```
