# 02 · IEEE 中文会议论文骨架

## 文档骨架（节序即论证链）

```
摘要（一段，含 2~3 个硬数字）
关键词（5~7 个，术语不重复标题已有词时优先补新词）
1 引言          —— 应用领域 → 单模态痛点 → 融合难点 → 数据集背景 → 前期思想来源 → 本文贡献列表（itemize，3~4 条，每条一句"做了什么"+半句"解决什么"）
2 相关工作      —— 2~3 个小节，每小节末句必须收束到"还缺什么，本文补什么"
3 数据集与问题定义 —— 数据集规模/划分/标注格式 + 形式化任务定义（公式）
4 方法          —— 总体结构（一张架构图）→ 各模块小节（每模块：动机一句 → 公式定义 → 设计理由）→ 损失函数
5 实验与结果分析 —— 设置 → 指标 → 总体比较 → 消融 → 鲁棒性/复杂环境 → 定性分析
6 讨论          —— 与最强基线的路线差异 + 局限（写真话，3~4 条）
7 结论          —— 方法复述两句 + 头条数字 + 未来工作
参考文献         —— thebibliography 内联（Tectonic 无 biber）
```

## 中文 IEEEtran 导言区（已验证可编译）

见 `assets/ieee-cn-template.tex`。要点：
- `\documentclass[conference]{IEEEtran}` + `\IEEEoverridecommandlockouts`
- `fontspec` + `xeCJK`，中文字体 `Noto Serif CJK SC`（本机已用户级安装，直接按名引用）
- 必备包：`cite, amsmath, amssymb, amsfonts, graphicx, booktabs, multirow, array, url, xcolor`
- 首行保留 `% !TeX program = xelatex`（对 Overleaf 友好；本地已被配置忽略，双保险有 shim）

## 图表纪律

- 架构图用 `figure*`（跨双栏），模块图用 `figure`（单栏）；宽表用 `table*`。
- 图题在图下、表题在表上；表注写清指标方向（↑/↓）与加粗/下划线约定（最优加粗、次优下划线）。
- **每个 `\label` 全文唯一**；复制图表代码块后第一件事就是改 label。
- 图片引用统一 `\includegraphics[width=0.95\linewidth]{fig/xxx}`，图全部放 `fig\` 子目录。

## 数字与单位写法

- 百分比在正文写 `62.4\%`，表格里列头带 `\%` 则单元格只写数字。
- 提升量写"个百分点"（与相对提升区分）；"较 X 提升 1.0 个百分点（$mAP$）"。
- 参数量 M、计算量 G、推理时间 ms，列头注明单位与方向：`参数量/M$\downarrow$`。

## 摘要公式化模板

背景痛点（2 句）→ 针对的 3~4 个挑战（一句排比）→ 方法名 + 各模块一句话（按数据流顺序）→ 实验数字（$mAP$/$AP_{50}$ 绝对值 + 对最强基线的提升 + 对单模态的提升）→ 一句收束（什么机制被验证有效）。

## 投稿前格式核对

- 目标期刊/会议要求英文摘要的，补 `Abstract`/`Index Terms`。
- 双盲评审：删作者块、删致谢。
- 参考文献格式按目标 venue 调整；arXiv 预印本条目在正式发表后更新出处。
