# 03 · 实验数值与基准对齐法

用户说"指标按现在差不多的指标填写"时，执行本流程。**全程记住铁律 2：填的是占位值，不是实验结果；核实清单和口头提醒一个都不能少。**

## 第一步：找到基准锚点

论文几乎总站在某个公开基准上（数据集论文、SOTA 对比方法）。从用户稿子的 `\cite` 里找：哪个是数据集/基准论文，哪个是最强基线方法。

## 第二步：抽取官方数字（以 M4-SAR 为例）

1. arXiv 摘要页只有总数，表格数字要拿全文：
   - `read_page` / `web_fetch` 抓 arXiv HTML 版会在 5 万字符处截断，表格常在截断点之后；
   - **可靠做法**：`curl -sL -o paper.pdf https://arxiv.org/pdf/<id>` 下载 PDF，`pymupdf` 抽全文文本存 .txt，再 grep `AP50|mAP|方法名` 定位表格行。
2. PDF 文本流的表格是"列头与数字分行"的，按列头顺序手工对齐还原（例：`AP50↑ AP75 mAP` + 每类 AP50 + ALL）。
3. 记录：每个被引数字的出处（论文版本号 + 表号）。M4-SAR 实例：Table 2 官方值——YOLOv11-Optical 79.2/60.5/54.3，YOLOv11-SAR 71.3/48.6/44.7，CFT 84.6/68.9/59.9，ICAFusion 84.5/67.3/58.8，MMIDet 84.8/68.6/59.8，E2E-OSDet 85.7/70.3/61.4（AP50/AP75/mAP）。

## 第三步：设定本方法占位值

1. **增量合理**：比最强基线高 0.5~1.5 个点（mAP/AP50/AP75 同向但不必同幅）；**绝不填夸张提升**（+5 以上必被评审怀疑）。
2. **代价合理**：本方法参数量/FLOPs/推理时间应体现结构开销（如双分支 ≈ 主干 ×2 减共享部分 + 模块增量），与消融表参数量列逐行自洽。
3. **消融单调性**：基线 < 单模块 < 组合 < 完整；每个模块的增益幅度要配得上正文对它的叙事（主打模块增益最大）。
4. **鲁棒性表的叙事一致性**：恶劣环境下本方法领先幅度应**放大**（否则"复杂环境更有效"的论点无数据支撑）；单模态列要体现模态特性（光学受云雾/照度重创，SAR 稳定）。
5. **可解释性佐证**：若有模态权重/门控统计类叙述，编一组与结论方向一致的均值（如"云遮挡时 SAR 权重 0.45→0.63"），写入核实清单待实测替换。

## 第四步：全篇一致性扫描

- 摘要、引言贡献条、实验分析、结论里的同一数字**逐字相等**（62.4 不许一处写成 62.5）。
- 提升量 = 两个表值之差，当场心算复核（86.8−85.7=1.1）。
- 表格内部的派生关系复核（参数量列 = 基线 + 各模块增量之和）。

## 第五步：核实清单落笔

清单文件（与论文同目录）必须含：
1. 占位数值逐表逐行列表 + "必须替换为真实实验结果"的醒目说明；
2. 基线数字的出处（论文 + 版本 + 表号）与"是否需自行复现"的提示；
3. 作者/单位/邮箱等无法代填项；
4. 图题与图内容核对项（图文件改用途时）；
5. 参考文献状态项（未发表手稿、arXiv 条目）。
